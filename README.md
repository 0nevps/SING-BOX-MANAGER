# Sing-Box Manager

这是一个在 Linux VPS 上管理 sing-box 服务端的工具。你可以在终端里按菜单操作，管理节点、用户、出口、证书和配置。

## 先认识几个词

- **节点（手机或电脑连接的入口）**：例如 REALITY、Hysteria2 或 WebSocket 节点。
- **用户**：一组可单独启用、停用和设置节点权限的连接身份。
- **出口（VPS 访问网络时使用的线路）**：可以为用户在不同节点上分别设置。
- **直连（DIRECT，不经过代理出口）**：由 VPS 直接访问网络。
- **连接密钥（UUID 或密码）**：客户端连接节点时使用的信息，请像密码一样保管。

## 安装与使用

安装和更新直接获取当前仓库 `main` 分支的完整源码，包括 Python 程序，无需手动下载其他文件。在 Debian/Ubuntu 上安装：

```bash
curl -fsSL https://raw.githubusercontent.com/0nevps/SING-BOX-MANAGER/main/install.sh | sudo bash -s -- 0nevps/SING-BOX-MANAGER
```

更新时选择“4 服务管理 → 6 更新管理程序”，或重新运行相同安装命令，即可获取 `main` 最新代码，保留数据和配置。不需要指定版本，也不依赖本项目的 tag 或 Release。彻底删除本工具时，选择“4 服务管理 → 7 卸载全部”，核对删除范围后输入 `yes`。

安装脚本会更改系统软件包、systemd 和 `/opt/sbmanager` 等目录。执行前请先阅读[安装与升级](docs/INSTALLATION.md)，检查安装脚本和 `main` 源码。

使用步骤：

1. 在支持的 Linux VPS 上，以 root 权限执行安装命令。
2. 安装器检查环境、准备 Python 3 和系统依赖，下载目标 commit 的源码并安全检查解压，同时下载并校验 sing-box。
3. 安装完成后，有交互终端时会显示主菜单，不会自动设置节点；无交互终端时，请运行 `sudo sbmanager`，已在 root 终端中时可运行 `sbmanager`。每次运行都先显示主菜单，包括没有节点数据的首次使用。
4. 选择“1 节点管理 → 2 添加节点”，逐个添加需要的节点；再通过“2 用户管理”添加用户并开通节点。保存后选择“4 服务管理 → 2 检查配置并启动服务”。之后仍需检查证书并用客户端测试连接。
5. 选择用户、节点或出口时，按名称找到对象并输入列表编号，不需要复制 ID。具体操作见[使用指南](docs/USER_GUIDE.md)。

主菜单：`1 节点管理`、`2 用户管理`、`3 出口管理`、`4 服务管理`、`5 备份与恢复`、`6 高级与帮助`、`0 退出`。各子菜单输入 `0` 返回，选择对象时输入 `0` 取消。列表默认以便于阅读的形式显示；原始设置 JSON 仅在“6 高级与帮助 → 1 查看原始设置JSON”中查看。切换出口时，直连是列表中的明确编号选项，不通过留空回车选择。删除、恢复等危险操作仍需确认。

你不需要手动安装 pip 包、创建 Python 虚拟环境或编写 sing-box JSON 配置。**安装完成或节点设置已保存，都不代表节点已经可以连接。** 证书申请和客户端连接仍受域名、网络及服务状态影响。

## 包含哪些功能

- 三种节点：VLESS + REALITY + Vision、Hysteria2、VLESS + WebSocket + TLS。
- 同一用户可以使用多个节点，每个节点分别设置使用权限和连接密钥。
- 出口类型可扩展，目前提供 SOCKS5 出口。
- 每个用户在每个节点上可保存多个出口，并选择其中一个使用，或选择直连（DIRECT，不经过代理出口）。
- 不支持 UDP 的代理出口会阻止 UDP 流量，不会偷偷改用 VPS 直连。
- 由 sing-box 通过 ACME 申请和续期证书，管理器提供检查功能。
- 查看节点分享链接、systemd 服务状态和日志。
- 修改配置前检查、备份，并通过操作锁避免同时写入；应用失败时尝试一起恢复管理数据和服务配置。

不包含网页管理面板、多 VPS 管理、流量计费、自动出口切换或 Cloudflare API 自动配置。

## 系统与网络要求

- 安装脚本支持 Debian 12/13 和 Ubuntu 22.04/24.04，系统需要使用 systemd；其他版本暂不支持。
- 安装和运行管理程序都要求 Linux + root。`sbmanager` 和 `python3 main.py` 均管理真实系统服务，统一使用 `/var/lib/sbmanager/` 保存数据、`/etc/sbmanager/config.json` 保存服务配置。VPS 需要能下载系统依赖、访问 GitHub API 和源码下载服务，以及下载 sing-box 官方发布文件。
- 安装器会检查和准备 Python 3，程序主要使用 Python 标准库。
- sing-box 兼容范围为 1.14.x，且必须支持 ACME Certificate Provider（证书申请功能）。
- 使用 HTTP-01 申请证书时，域名必须指向正确地址，公网 TCP 80 必须能到达 VPS 源站。不支持 DNS-01 验证方式。
- Cloudflare 的 DNS 解析、代理开关和 Origin Rules（回源规则）需要自行设置，程序不会代为配置。

## 安装和升级如何处理数据

安装器使用 Bash，负责安装程序和准备环境；管理程序使用 Python，负责菜单、用户、出口和配置。

安装器只接收仓库名，通过 GitHub API 获取 `main` 当前提交，再通过 HTTPS 下载该提交的完整源码并安全检查解压。安装过程中即使仓库有新提交，本次下载仍固定在已选定的提交。sing-box 从其官方 GitHub Release 下载并按官方摘要校验。

程序保存到 `/opt/sbmanager/builds/` 下独立目录，通过 `current` 链接切换。每次运行安装器都会获取当前源码，不会因已安装而跳过。用户、节点、服务配置和备份与程序分开保存；更新前保留旧程序和数据备份，失败时尝试恢复旧程序。恢复后请检查服务状态和数据。

## 项目结构与开发测试

相关文档：

- [贡献指南](AGENTS.md)：代码组织、命名、测试和提交要求。

主要文件和目录：

```text
install.sh       安装脚本
main.py          Python 启动入口
sbmanager/       菜单、用户和节点管理、配置生成及系统服务操作
tests/           自动化测试
docs/            安装、使用和故障排查等文档
```

开发时可在 macOS/Linux 上运行模拟系统操作的 unittest，不需要 root 或第三方 Python 包：

```bash
python3 -m unittest discover -s tests -p 'test_*.py' -v
```

`python3 main.py` 不是隔离的开发入口：它与安装后的 `sbmanager` 一样要求 Linux + root，使用相同的管理数据和服务配置，并操作真实系统服务。可用 `--sing-box /path/to/sing-box` 指定 sing-box 程序文件；这不会隔离数据或服务。真实安装和服务操作应在可丢弃的 Debian/Ubuntu 环境中验证。

自动化测试包含用户节点权限隔离、出口删除保护、连接密钥重置、用户停用和删除、文件权限与敏感信息隐藏、写入失败、多个进程同时修改以及菜单操作。安装脚本可用 `bash -n install.sh` 和 ShellCheck 检查；这些检查不能代替安装、systemd、证书和客户端连接的 Linux 实测。

## 安全提醒

数据和密钥文件使用 `0600` 权限，敏感目录使用 `0700` 权限。管理数据、备份和导出文件中可能含有明文密码或连接密钥，请妥善保管。

日志、问题反馈和 Git 提交中不要包含密码、私钥或完整分享链接。应用配置前需要先检查和备份；应用失败时尝试同时恢复管理数据和配置。恢复失败后不要删除恢复记录来强行继续操作。
